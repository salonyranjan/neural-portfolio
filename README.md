## 🌌 What is Neural Portfolio?

**Neural Portfolio** turns a static résumé into a **live, force-directed 3D graph**. Every node is a repository, every edge is a shared technology, and node size scales with project complexity — all auto-synced from your GitHub activity, nightly, with zero manual updates.

> 🎯 **The insight:** recruiters don't just need a list of what you've built — they need to *feel* how deep your skills interconnect. A graph makes that obvious in three seconds flat.

## ✨ Key Features

| | Feature | Description |
|:---:|:---|:---|
| 🌌 | **Interactive 3D Graph** | Force-directed node physics with orbit, pan, and zoom — a custom `requestAnimationFrame` loop holds 60 FPS at any graph size |
| 🔗 | **Live GitHub Sync** | A Python scraper pulls repo metadata, stars, languages, and deployment URLs on a schedule via GitHub Actions |
| 🚀 | **Smart Deployment Detection** | Auto-detects Vercel and Streamlit URLs, surfacing "Live Demo" ahead of source code for recruiter-first UX |
| 📊 | **Complexity-Weighted Nodes** | Node size scales with a complexity score (LOC, tech diversity, stars) — hierarchy emerges without manual curation |
| 🎨 | **Distance-Based Edge Fading** | Edges fade as nodes separate, killing spaghetti-graph clutter at any zoom level |
| 🔍 | **⌘K Global Search** | Command-palette node finder — camera smoothly flies to the match |
| 📋 | **Contextual Sidebar** | Tech chips, complexity score, live demo link, GitHub stats, and an AI-generated summary on every click |
| 📱 | **Touch & Mobile Ready** | Pinch-to-zoom, swipe-to-orbit, tap-to-select — physics scales to mobile GPU budgets automatically |

## 🤔 Why I Built This

Static résumés are linear — they list projects sequentially but hide the signal that actually matters: **how skills and projects relate to each other.**

A flat list can't show that RAG pipelines, vector databases, and LLM tooling form a coherent specialization, or that the 3D web work shares a rendering philosophy with the geospatial and data-viz work. **Neural Portfolio makes those connections visible in three seconds.**

| 🔧 Problem | 💡 Solution |
|:---|:---|
| Spaghetti graphs at high node density | Distance-based edge fading + complexity-weighted scaling creates natural hierarchy |
| Stale deployment links — GitHub doesn't track "where it's live" | A deployment detector parses README + repo topics to surface live URLs automatically |
| 60 FPS with 50+ nodes — force simulation is expensive | A custom `requestAnimationFrame` loop decoupled from React's render cycle |

## 📦 Quick Start

**Prerequisites:** Node.js ≥ 18, Python ≥ 3.10, Git, a [GitHub token](https://github.com/settings/tokens)

```bash
# 1. Clone
git clone https://github.com/salonyranjan/neural-portfolio.git
cd neural-portfolio

# 2. Backend
cd backend
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Frontend
cd ../frontend
npm install
```

**Configure secrets** — create `backend/.env`:

```env
GITHUB_TOKEN=your_github_personal_access_token
GITHUB_USERNAME=salonyranjan
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
AWS_S3_BUCKET=your-bucket-name
AWS_REGION=us-east-1
```

and `frontend/.env.local`:

```env
NEXT_PUBLIC_GRAPH_URL=https://your-bucket.s3.amazonaws.com/graph.json
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

> 🔐 Both files are git-ignored — never commit real tokens.

**Run it:**

```bash
# Generate graph.json
python scraper/github_scraper.py

# Start the API
uvicorn main:app --reload --port 8000        # → localhost:8000/docs

# Start the frontend
npm run dev                                   # → localhost:3000
```

## 🚀 Deployment

**Frontend → Vercel:** push `frontend/` to GitHub, import at [vercel.com/new](https://vercel.com/new), set root directory to `frontend/`, add env vars, deploy. Auto-redeploys on every push.

**Backend → AWS EC2:**
```bash
git clone https://github.com/salonyranjan/neural-portfolio.git
cd neural-portfolio/backend
pip install -r requirements.txt
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```
> ⚠️ Open port 8000 in your EC2 Security Group and point `NEXT_PUBLIC_API_BASE_URL` to the EC2 public IP.

**Nightly scraper → GitHub Actions:** `.github/workflows/scraper.yml` runs at 02:00 UTC, refreshes `graph.json` on S3, and triggers a Vercel redeploy.

## ❓ FAQ

<details>
<summary><b>How often does the graph sync with GitHub?</b></summary><br/>

Nightly, at 02:00 UTC via GitHub Actions — or trigger a manual run from the Actions tab after pushing a major project. The frontend fetches `graph.json` fresh on every page load.
</details>

<details>
<summary><b>How does Smart Deployment Detection work?</b></summary><br/>

`deployment_detector.py` checks three sources per repo: the `homepage` field, README URL patterns, and repo topics (`vercel-deployed`, `streamlit-app`). Any match gets promoted to the primary CTA in the sidebar, above the source link.
</details>

<details>
<summary><b>Why decouple the physics loop from React?</b></summary><br/>

React's render cycle can be delayed by state updates and re-renders. Running the force simulation in a native `requestAnimationFrame` callback (not `useEffect`) keeps physics ticking every frame regardless of React's workload — so the graph stays smooth even mid-interaction.
</details>

<details>
<summary><b>Why Pinecone instead of a local vector store?</b></summary><br/>

Sub-20ms ANN lookups with zero infrastructure to manage. The free tier comfortably handles a portfolio's worth of repository embeddings. ChromaDB or FAISS work fine as self-hosted alternatives.
</details>
